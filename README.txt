ЛИДА-СЕРВИС — многостраничный сайт

Главная страница index.html сохранена по структуре исходного файла и содержит все исходные блоки: калькулятор, виды лизинга, преимущества, процесс, условия, документы, FAQ, о компании, партнёры, клиенты, CTA, форма и контакты.

Отдельные страницы только для четырёх видов лизинга:
- leasing-auto.html
- leasing-special.html
- leasing-equipment.html
- leasing-realestate.html

Раздел «Раскрытие информации» находится на disclosure.html. Тексты взяты с официальной страницы компании.

Общие header/footer вынесены в components/header.html и components/footer.html. Стили — css/style.css. Общая логика — js/main.js.

Папка docs предназначена для локальных копий документов. В текущем архиве бинарные копии не включены; три документа доступны по официальным URL, указанным на странице disclosure.html. Свидетельство о регистрации и свидетельство о включении в реестр в исходном блоке не имели доступной прямой ссылки.


Обновление: верхнее меню главной страницы ведёт к блокам этой страницы. Отдельные страницы предусмотрены только для 4 видов лизинга. «Раскрытие информации» доступно кликабельным заголовком в правой колонке футера. Блок «Документы» на главной восстановлен по исходному файлу.
