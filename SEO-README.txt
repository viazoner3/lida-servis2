SEO И АНАЛИТИКА — ООО «ЛИДА-СЕРВИС»

В версии v10 подготовлена SEO-база сайта и единая точка будущего подключения Яндекс.Метрики.

1. SEO
- Уникальные title и description для главной, четырёх услуг, раскрытия информации и политики конфиденциальности.
- rel="canonical" на основных индексируемых страницах.
- Open Graph и Twitter Card для корректных превью страниц.
- Schema.org JSON-LD: FinancialService/Organization, WebSite, Service и BreadcrumbList.
- robots.txt и sitemap.xml.
- Страница 404.html.
- Политика конфиденциальности исключена из sitemap и закрыта от индексации (noindex,follow).
- Исходные HTML-файлы, использованные при разработке, удалены из производственной версии, чтобы не создавать дубли страниц в поиске.
- Основной контент страниц доступен непосредственно в HTML; шапка и подвал также присутствуют в HTML до выполнения JavaScript.
- Добавлены alt для изображений, lazy loading для второстепенных изображений и aria-label для полей форм.

2. ЯНДЕКС.МЕТРИКА
Файл js/metrika.js — единая точка подключения счётчика.
Сейчас счётчик отключён. После создания счётчика в Яндекс.Метрике замените:
    var COUNTER_ID = 0;
на фактический ID счётчика.

Загрузка счётчика предусмотрена после согласия пользователя на cookie/аналитику.
События, подготовленные в коде:
- cta_application — нажатие CTA «Оставить заявку»;
- calculator_open — переход к калькулятору;
- form_submit — отправка заявки (демо-форма фиксирует событие до показа сообщения об успехе);
- phone_click — клик по телефону;
- email_click — клик по e-mail;
- viber_click — переход в Viber;
- instagram_click — переход в Instagram;
- document_download — скачивание/открытие PDF, JPG, DOC/DOCX, XLS/XLSX.

В Яндекс.Метрике цели можно создать как «Целевое событие» с соответствующими идентификаторами.

3. ПОСЛЕ ПУБЛИКАЦИИ
- Добавить сайт в Яндекс.Вебмастер.
- Подтвердить права на домен.
- Добавить sitemap.xml.
- Проверить robots.txt.
- Проверить каждую страницу через инструменты проверки URL.
- Проверить микроразметку.
- Создать счётчик Яндекс.Метрики и вписать его ID в js/metrika.js.
- Настроить цели по списку выше.
- Включить Вебвизор и карту кликов после проверки требований к обработке данных.
- После публикации проверить 404, HTTPS, canonical, отсутствие дублей URL и корректность мобильной версии.

4. ВАЖНО
Текущая форма заявки в сайте демонстрационная: JavaScript не отправляет заявку на сервер, а только показывает сообщение об успешной отправке. Для реального бизнеса потребуется подключение backend/CRM/e-mail обработчика. Цель form_submit после этого следует считать успешной только после подтверждённой отправки на сервер.
